# Zomato Restaurant Sentiment Analysis

This project analyzes Zomato restaurant reviews using NLP and Machine Learning techniques.

## Key Highlights
- Exploratory Data Analysis (EDA)
- Text preprocessing and TF-IDF vectorization
- Sentiment classification using ML models
- Model evaluation and selection
- Model saved and tested on unseen data (deployment ready)

## Tools & Technologies
- Python
- Pandas, NumPy
- Scikit-learn
- NLTK
- Google Colab

## Final Model
Logistic Regression was selected as the final model based on performance and stability.
